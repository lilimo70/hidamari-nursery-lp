\f0\fs26 \cf0 # Project Rules\
\
## Project\
This is a static one-page landing page for a nursery school recruitment website.\
\
## Tech Stack\
- HTML\
- CSS\
- JavaScript\
- No framework\
- No build tools\
\
## Coding Style\
- Write readable, maintainable code.\
- Keep CSS formatted with proper line breaks and indentation.\
- Do not minify CSS or HTML.\
- Organize CSS by section with comments.\
- Use meaningful class names.\
- Prefer BEM-style class names where possible.\
- Do not use overly generic class names for new code.\
- Do not rewrite the entire project unless explicitly requested.\
- Do not change text content unless explicitly requested.\
- Do not rename image files unless explicitly requested.\
\
## CSS Rules\
- Use 2-space indentation.\
- One CSS property per line.\
- Add blank lines between selector blocks.\
- Keep related styles grouped together.\
- Use section comments like:\
  - Base\
  - Header\
  - Hero\
  - Message\
  - Feature\
  - Schedule\
  - Staff Voice\
  - FAQ\
  - Contact\
  - Footer\
  - Responsive\
- Use CSS custom properties from :root whenever possible.\
- Avoid unnecessary !important.\
- Avoid unnecessary complex selectors.\
- Keep responsive styles at the bottom of the file.\
\
## Class Naming\
- Use BEM-style naming for new sections.\
- Example:\
  - feature\
  - feature__inner\
  - feature__grid\
  - feature__card\
  - feature__image-wrap\
  - feature__image\
  - feature__deco\
  - feature__title\
  - feature__text\
- Modifier examples:\
  - feature__card--01\
  - feature__card--02\
  - button--primary\
  - button--outline\
\
## Design Rules\
- Preserve the existing Figma-based design.\
- Do not make visual design changes unless requested.\
- Keep the warm, gentle, modern nursery-school look.\
- Main colors:\
  - Background: #fffaf2\
  - Beige: #eee6d8\
  - Line: #e6ded0\
  - Text: #413833\
  - Green: #4c8c8a\
  - Orange: #df735d\
\
## Work Rules\
- Only edit the requested section.\
- Before changing a large structure, explain the plan first.\
- After editing, report:\
  1. Changed files\
  2. Changed section\
  3. What was fixed\
  4. Any remaining issues}
